## Overview

Welcome to my personal portfolio repository!

I am a Computer Engineering graduate with an interest in web development and hands-on experience in IT support. This website serves as a central place to present my technical capabilities, academic projects, and professional background.

The portfolio was built to provide a clean and accessible way for recruiters, potential employers, and fellow developers to explore my work and learn more about my experience.

## Features

- **Personal Introduction** – An overview of my background, interests, and professional goals.
- **Technical Skills** – A categorized presentation of my programming languages, development tools, and technical knowledge.
- **Project Showcase** – Selected projects featuring descriptions, technologies, and visual presentations.
- **Resume Section** – Educational background, work experience, and certificates.
- **Contact Section** – A convenient way to connect with me.
- **Dark and Light Themes** – Switch between different visual themes.
- **Responsive Layout** – Designed to provide a consistent browsing experience across desktop and mobile devices.
- **Interactive Animations** – Smooth transitions and visual interactions throughout the website.

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR_USERNAME/my-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd my-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit the following address in your browser:

```text
http://localhost:3000
```

## Production Build

To generate an optimized production build, run:

```bash
npm run build
```

To start the production server after a successful build:

```bash
npm start
```
